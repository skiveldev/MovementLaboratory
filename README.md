# Movement Laboratory

A Unity 2D movement prototype created with Unity 6000.5.10f1 and the Universal Render Pipeline.

## Third-party assets

This repository does not redistribute the **Berie's Adventure Seaside Asset Pack** because its license prohibits sharing the original or modified asset files for free.

- Author: **Crusenho**
- Download: <https://crusenho.itch.io/beriesadventureseaside>
- Required local path: `Assets/_Project/Sprites/Berie's_Adventure_Seaside_Asset_Pack_Free`

Download the pack from the author's page and extract it into the required local path before opening the project in Unity.
